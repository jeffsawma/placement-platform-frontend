# Système de placement — Frontend

Frontend React d’une plateforme de placement développée en équipe dans le cadre de mon stage en développement full-stack au Cégep Gérald-Godin en 2026.

La plateforme permet de gérer le processus de placement des étudiants à travers plusieurs rôles : étudiants, employeurs, administrateurs et responsables de stage.

## Aperçu du projet

L’application propose une interface Web adaptée au rôle de l’utilisateur.

Les étudiants peuvent notamment :

- rechercher des offres d’emploi et de stage ;
- soumettre et suivre leurs candidatures ;
- créer des demandes de stage ;
- consulter les réponses des employeurs et les notifications reçues.

Les employeurs peuvent notamment :

- gérer leur profil d’entreprise ;
- publier et gérer leurs offres ;
- consulter les candidatures reçues ;
- envoyer des offres de stage directes ;
- confirmer certaines étapes du processus de placement.

Les administrateurs disposent également d’interfaces permettant de gérer les cégeps, les domaines d’études et différents éléments de la plateforme.
